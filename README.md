# じゃんけん道場

ブラウザで遊べるじゃんけんアプリです。`index.html` をブラウザで開くだけで動きます。

- グー・チョキ・パーをボタンかキー 1・2・3 で選ぶ
- あいこのときは「あいこでしょ！」で続行
- 勝ち・負け・あいこ・連勝・勝率・最高連勝を記録（ブラウザに保存）
- ライト／ダークテーマ対応

## クラウド保存（Supabase）

メールアドレスとパスワードでログインすると、勝敗の記録が Supabase に保存され、別の端末でも同じ記録を見られます。ログインしなくても今まで通り遊べます（記録はブラウザに保存）。

- テーブル: `janken_stats`（通算成績）、`janken_rounds`（1回ごとの勝負）
- 行レベルセキュリティで、自分の記録しか読み書きできません
- `index.html` にある公開用キー（publishable key）は公開しても問題ないキーです
